<h1 align="center">OpenCloudModel</h1>

<p align="center"><b>Charting the clouds.</b> ☁️🧭</p>

---

Every cloud provider describes the same ideas in its own words.
**OpenCloudModel** is an academic research project that reads how providers name and
describe their services, and charts where they meet.

### 🔭 What we're up to

- Reading public cloud documentation — politely, slowly, and on the record.
- Comparing how the same concepts are named across providers.
- Building an open, vendor-neutral model of the cloud landscape.

### 🤖 Our crawler

**OpenCloudModelBot** reads public documentation only. It obeys `robots.txt`, keeps a
gentle pace, and always says who it is. Its sources, addresses and opt-out are listed at
**[opencloudmodel.org/crawler](https://opencloudmodel.org/crawler/)**.

### 📬 Get in touch
